# Словарь токенов проекта Talking Travel

## 1. Ширина макета и контейнер

| Параметр | Значение | Токен |
|----------|----------|-------|
| Ширина макета | 1440 px | — (справочно) |
| Ширина содержательного контейнера | 1140 px | `--container` |
| Внешние поля контейнера на 1280 | 48 px | `--space-12` |
| Внешние поля контейнера на 768 | 32 px | `--space-8` |
| Внешние поля контейнера на 360 | 16 px | `--space-4` |

## 2. Сетка

| Параметр | Значение | Токен |
|----------|----------|-------|
| Промежуток между колонками | 24 px | `--grid-gap` |
| Промежуток между карточками | 24 px | `--grid-gap` |
| Промежуток между строками в списке постов | 16 px | `--space-4` |
| Выравнивание контейнера | по центру | `margin-inline: auto` |

**Сетки по секциям:**

| Секция | Раскладка |
|--------|-----------|
| Hero | 2 колонки: текст (≈55%) + изображение (≈45%) |
| Featured Destination | 2 колонки: изображение (≈45%) + текст (≈55%) |
| Discover the world | 4 колонки равной ширины |
| Join our next destination | 1 колонка, форма по центру |
| Recent story entries | 2 колонки: большая карточка (≈55%) + список малых (≈45%) |
| Blog hero | 1 колонка: заголовок + видео-превью |
| Blog body | 2 колонки: коллаж (≈45%) + текст (≈55%) |
| Highlights | 3 колонки равной ширины |

## 3. Типографика

### 3.1. Семейства шрифтов

| Назначение | Значение | Токен |
|------------|----------|-------|
| Основной текст | Inter, system-ui, sans-serif | `--font-body` |
| Заголовки | Inter, system-ui, sans-serif | `--font-heading` |

**Примечание:** по макету используется одно семейство с разными начертаниями. Если в Figma есть второе — уточнить.

### 3.2. Размеры и начертания

| Элемент | Размер | Начертание | Интерлиньяж | Токен |
|---------|--------|------------|-------------|-------|
| `h1` hero / статьи | 64 px | 700 | 1.05 | `--step-6` |
| `h2` заголовки секций | 40 px | 700 | 1.15 | `--step-5` |
| `h3` заголовки карточек | 20 px | 600 | 1.3 | `--step-2` |
| `h4` мелкие подзаголовки | 18 px | 600 | 1.3 | `--step-1` |
| Основной текст (`p`) | 16 px | 400 | 1.5 | `--step-0` |
| Мелкий текст (подписи, описания) | 14 px | 400 | 1.5 | `--step--1` |
| Надзаголовок (eyebrow) | 13 px | 600 | 1.4 | `--step--2` |
| Подпись под изображением (figcaption) | 14 px | 400 | 1.4 | `--step--1` |
| Цитата (blockquote) | 28 px | 600 | 1.3 | `--step-4` |
| Кнопка | 15–16 px | 500 | 1.0 | `--step-0` |
| Заголовок формы «Share your travels» | 20 px | 600 | 1.3 | `--step-2` |

### 3.3. Регистр и разрядка

| Элемент | Регистр | Межбуквенное расстояние | Токен |
|---------|---------|------------------------|-------|
| Надзаголовок (eyebrow) | uppercase | 0.08em | `--tracking-wide` |
| Заголовки | normal | normal | — |
| Основной текст | normal | normal | — |
